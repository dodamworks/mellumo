# 멜루모 · Mellumo

Postiz 기반의 오픈소스 AI SNS 자동화 프로젝트입니다.

**현재는 기반 구축 단계입니다.** Postiz v2.25.3의 기능 코드를 유지하며 시작합니다. 앱 화면에는 아직 Postiz 이름과 디자인이 남아 있습니다. AI가 목표부터 작업 완료까지 수행하는 흐름은 앞으로 연결할 개발 방향입니다.

- 기존 캘린더·작성기·SNS 연결·미디어·예약·분석·팀 기능을 최대한 재사용합니다.
- 내장 에이전트와 MCP/REST, Temporal 발행 워크플로를 활용합니다.
- 목표·작업 상태·복구·완료 확인을 연결합니다. 매 게시물의 사람 승인을 기본 전제로 두지 않습니다.
- 실제 SNS 및 AI 사용에는 운영자의 키·권한·공급자 비용이 필요할 수 있습니다.
