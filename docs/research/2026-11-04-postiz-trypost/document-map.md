## 저장소 문서 읽기 우선순위

1. 실제 실행 파일과 잠긴 의존성, 현재 스키마/모델.
2. 고정 릴리스에 들어 있는 배포 절차와 CI/테스트.
3. 조사일의 외부 공식 운영·사용·API 문서.
4. 과거 설계안/계획 및 생성된 프레임워크 지침.

외부 문서가 반드시 더 정확한 것도, 저장소의 모든 문서가 현재 구현을 설명하는 것도 아니다. Postiz developer guide의 NX/Redis worker, TryPost independent-posts 설계의 테이블 분리는 현재 코드와 대조해야 한다.

제품 정책/사용법은 공식 문서를, 구현·권한 강제·상태 전이는 코드를 우선 근거로 삼았다. 출처별 시차와 모순은 상위 비교 문서에 남겼다. 전체 코드 보안 감사나 전체 문서의 완전성 인증은 이번 범위가 아니다.
