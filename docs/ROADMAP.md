# Development direction

## Foundation prepared

Import Postiz with ancestry and notices, establish Mellumo repository identity, document source setup, and separate local data from public source. The application retains upstream behavior and visible branding at this stage.

## Next: a useful delegated task

Connect an objective to existing agent/tools: prepare one post for a configured channel, schedule or publish within the delegated scope, follow the result and report the actual outcome. Persist enough task state to distinguish waiting, partial completion, failure and success. This is not yet implemented.

Reuse the composer, channel providers, media handling and workflows. Change branding and source/license access deliberately; avoid mass renaming internal identifiers. Keep human approval configurable rather than requiring it for every task.

## Later

Connect richer brand/objective memory, task recovery, observed metrics and follow-up work. Add channels or TryPost-inspired tool contracts only when an actual task needs them. Comments/DM automation and autonomous growth optimization are not current delivered features.

No release date or production-readiness claim is made by this roadmap.
